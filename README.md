# AIVERA — Concept Website

A cinematic landing page concept created for an application to AIVERA.

The project explores how I would approach the intersection of **web development, digital marketing, visual design and AI-focused education** while keeping the experience aligned with AIVERA's existing positioning.

## About the Project

AIVERA is a global education platform built to prepare professionals, companies and future leaders for a world shaped by artificial intelligence, automation and digital transformation.

This project is an independent concept created to demonstrate my approach to:

- Landing page design
- HTML, CSS and JavaScript
- Responsive web development
- Campaign thinking
- Digital advertising concepts
- Short-form video
- UX and visual storytelling
- Brand-focused web experiences

The website is designed as a campaign-style experience rather than a traditional portfolio page.

## What I Built

### Web

- Responsive landing page
- Custom HTML structure
- Custom CSS styling and animations
- JavaScript interactions
- Responsive navigation
- Campaign-focused sections
- Video integration
- Offline-friendly asset structure

### Marketing

The site includes original campaign concepts created specifically around AIVERA's positioning.

These include:

- Static advertising creative
- Animated campaign creative
- Short-form vertical video concept

The purpose is to demonstrate how I would connect **social content with the landing page experience**.
